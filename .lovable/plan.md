# Desktop player and sidebar controls

## Build
- Dock the desktop mini player flush to the bottom and screen edges beside the sidebar, while keeping its current mobile placement.
- Add a desktop sidebar control that collapses the menu to an icon rail and expands it again.
- Move desktop page content, top navigation, and the docked player with the sidebar state so no content is covered.
- Style the desktop volume track and marker with the same shared gold progress control used by playback.

## Verification
- Play a song at desktop size and confirm the mini player is flush with the bottom edge.
- Collapse and reopen the sidebar, confirming the page and player resize correctly.
- Confirm the volume and playback sliders have matching tracks and position markers.
