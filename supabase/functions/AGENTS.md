- Push goes to two OneSignal apps (website web push + Android app com.loveworld.worship) through supabase/functions/_shared/onesignal.ts, which takes each app's id from its os_v2_app key (configured ids are only a fallback for legacy keys); in-app links go to phones as data.deep_link and to browsers as web_url, never url — why: each app has its own REST key, a key paired with the wrong app id is refused, and a url would open the phone's browser instead of the app screen.
